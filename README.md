# 🚀 Personal Portfolio

A modern and interactive developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and React Three Fiber.

Inspired by immersive 3D experiences and clean engineering-focused portfolio design, this project combines smooth animations, modern UI, and scalable architecture to showcase my work, skills, and projects.

---

## ✨ Features

* Modern responsive UI
* Interactive 3D Hero Section
* Smooth animations using Framer Motion
* Tech stack showcase
* Featured projects section
* Engineering principles section
* Clean and scalable folder architecture
* Reusable component-based design
* Optimized performance and lazy loading

## ⚡ Getting Started

### Clone the repository

```bash
git clone https://github.com/SG-07/portfolio.git
```

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```
